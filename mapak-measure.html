Step 1 — Phone ko hi reference banao

Koi card ya calibration nahi chahiye. Sirf apne phone ki lambai ek baar set karo — phir usi se object par nishan lagakar naapo.

⚠ Cover utaar do. 1.5mm ka case dono taraf = 2% error, 3mm ka = 4% — ye poora fayda kha jata hai. Aur agar aap hamesha cover ke saath rakhte ho, toh cover ke saath hi ruler se naap ke wahi value daalo.

Kitni baar phone rakha (end-to-end)?
Reference: —

💡 Phone ko 2-3 baar end-to-end rakh kar nishan lagao — reference jitna lamba, error utna kam. 1 baar = 0.47%, 3 baar = 0.16%.

⚠ Nishan hamesha object ke seedhe hisse par lagao. Mude hue hisse par phone rakhoge toh photo me nishan ke beech ki doori chhoti dikhegi aur scale galat ho jayegi.

Tilt sensor: waiting…

Object ko flat surface par rakho, phone ko seedha upar se (90°) pakdo — tilt indicator green hone tak wait karo — aur ek reference object (card / coin) usi frame me rakho.

⚠ Sabse badi galti: reference card ko object ke same height/plane par rakhna zaroori hai. Agar object mota hai (dabba, kitaab) aur card table par pada hai, toh 40mm thickness = ~9% error. Card ko object ke upar rakho, table par nahi.
