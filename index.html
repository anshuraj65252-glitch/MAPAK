MAPAK मापक

Camera + GPS measuring — length (curved too), distance & speed

⚠ Secure connection needed

Camera aur GPS access ke liye ye page HTTPS (ya localhost) par open hona chahiye. File ko direct kholne (file://) par browser permissions block kar sakta hai — is HTML ko kisi static host (GitHub Pages / Netlify Drop) par daal kar try karo, ya Claude ke andar hi is preview ko use karo.

Step 1 — Capture

Object ko flat surface par rakho, phone ko seedha upar se (90°) pakdo, aur ek reference object (card / coin) usi frame & usi plane me rakho. Yehi scale accuracy decide karta hai.

Step 2 — Set scale

Reference object ke 2 known edges par tap karo (uski poori known length ke dono end points).
