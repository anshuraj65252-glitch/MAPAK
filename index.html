⚠ Secure connection needed

Camera, GPS aur AR ke liye ye page HTTPS (ya localhost) par open hona chahiye. File direct kholne (file://) par browser permissions block kar sakta hai — kisi static host (GitHub Pages / Netlify Drop) par daalo, ya isi preview me try karo.

Tilt sensor: waiting…

Step 2 — Set scale

Reference ke 4 corners tap karo (order: top-left → top-right → bottom-right → bottom-left).
